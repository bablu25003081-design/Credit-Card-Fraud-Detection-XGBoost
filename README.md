# Credit Card Fraud Detection using XGBoost

## Case Study 2

### Problem Statement
The aim of this project is to develop a machine learning system that can detect fraudulent credit card transactions. The system analyzes transaction data and classifies transactions as legitimate or fraudulent.

### Objective
- To detect fraudulent credit card transactions.
- To preprocess and analyze transaction data.
- To train an XGBoost classification model.
- To evaluate the performance of the trained model.

### Technology Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Jupyter Notebook

### Machine Learning Algorithm
**XGBoost (Extreme Gradient Boosting)** is used as the classification algorithm for detecting fraudulent transactions.

### Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training using XGBoost
6. Model Evaluation
7. Fraud Detection

### Expected Outcome
The system identifies whether a credit card transaction is **fraudulent or legitimate** based on the given transaction features.

### Conclusion
The Credit Card Fraud Detection system demonstrates how machine learning can be used to identify suspicious transactions and help improve financial transaction security.
